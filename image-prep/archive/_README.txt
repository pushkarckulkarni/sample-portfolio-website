ARCHIVE
============================================================
After the processor runs, your original full-size photographs
are moved here into a timestamped folder. Nothing is deleted.

If a batch comes out wrong — bad crop, too compressed — copy
the originals back into inbox/ and run it again with different
settings.

This folder is NOT uploaded to Hostinger. It will grow large.
Once you are happy with a batch and have the originals backed
up elsewhere, you can safely empty it.
