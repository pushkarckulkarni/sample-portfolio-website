HOME BANNER, PHONE CROP (PORTRAIT)
============================================================
Drop full-size photographs in THIS folder.

They will become : 1200 x 1500 px  (4:5)
File size budget : under 220 KB
Resolution       : 72 DPI
Renamed to       : 01.jpg, 02.jpg, 03.jpg ... in alphabetical order

So name your files so they sort into the order you want them shown,
for example 01-entrance.jpg, 02-courtyard.jpg, 03-stair.jpg.

Output lands in : website/content/home/hero-mobile/

Then run:
    python3 image-prep/process.py
    python3 tools/build.py
